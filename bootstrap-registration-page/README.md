# New Frontier Bootstrap Registration Page

A responsive community registration demo built with HTML, CSS, and
Bootstrap. This project demonstrates Bootstrap forms, grid layouts,
tables, images, navigation, and utility classes.

## Features

- Responsive navbar with Home, About, and Contact links
- Collapsible hamburger menu on smaller screens
- Registration form with first name, last name, email, and password
- Required terms agreement checkbox
- Form validation feedback and a demo success message
- First and last name fields displayed side-by-side on larger screens
- Striped, hoverable table containing hard-coded sample users
- Responsive table wrapper for smaller screens
- Full-width responsive banner image
- Circular image with sizing adjusted through a CSS media query
- One button visible at all screen sizes
- A second button hidden below the medium Bootstrap breakpoint

## Technologies Used

- HTML5
- CSS3
- Bootstrap 5.3.8
- JavaScript for form validation and button interactions
